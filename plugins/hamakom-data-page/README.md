# hamakom-data-page

בניית עמוד **דאטה-ז'ורנליזם סקרולי-טלינג** ל"המקום הכי חם בגיהנום" (RTL עברית, vanilla JS),
ואריזתו כתוסף WordPress מבודד ב-iframe.

## הדפוס

1. **סיקור-מקדים (חובה):** מקבלים את תחום הסיקור → שולפים את **כל** הכתבות שהמקום פרסמה בו
   דרך WP REST API הציבורי (`ha-makom.co.il/wp-json/wp/v2/...`) → מחלצים נתונים, ציטוטים,
   כתבות/תחקירים בולטים, וציר אירועים. רק אז בונים.
2. **בנייה:** מעתיקים את `template/index.html` (שלד עובד — מנוע scrolly + מותג + רספונסיב),
   מרכיבים קומפוננטות מ-`components.md`, ממלאים נתונים מהסיקור; טקסט עריכתי → פלייסהולדר.
3. **אריזה:** תוסף WordPress מבודד (iframe) מ-`wp-plugin/`.

## מה בפנים (`skills/hamakom-data-page/`)

| קובץ | תוכן |
|------|------|
| `SKILL.md` | הדפוס המלא, כללי מותג/קול/רספונסיב, צ'קליסט |
| `template/index.html` | שלד עמוד עובד (מנוע + מותג + רספונסיב + דמו) |
| `components.md` | ספריית קומפוננטות: וופל, בועות, ברי קצב, ציר זמן, רשת מושגים, שו״ת, מפה |
| `wp-plugin/` | סקאפולד תוסף iframe מבודד |

הסקיל מופעל אוטומטית כשמבקשים "עמוד דאטה / תחקיר-נתונים חדש" או "עוד אחד כמו יו״ש".
