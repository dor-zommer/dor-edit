# hamakom-newsletter — הניוזלטר השבועי

בונה גיליון שבועי מלא בעיצוב **HaMakom DS 2026**, קרוב ככל האפשר לגיליון שנשלח בפועל, עם
מקסימום אוטומציה ומינימום מילוי ידני.

## עיצוב (מקור אמת)

- **כותרות:** Suez One. **גוף:** IBM Plex Sans Hebrew. שתיהן Google Fonts (`@import`), עם
  fallback (`Frank Ruhl Libre` / `Heebo`). **לא** HaMakom מוטמע — פונט מותג נופל ברוב תיבות המייל.
- **פלטה:** שנהב `#faf9f5` · דיו `#141413` · טרקוטה `#D97757` · מרווה `#788C5D` · אברש `#8E6FA8`.
  פס-חתימה טריקולור בראש. תואם `plugins/hamakom-visuals/design-system/HAMAKOM-DS-2026.md`.
- **חוק המקף:** אסור קו מפריד ארוך (—/–). ה-build מנרמל אוטומטית ל-`-` עם רווחים. חל על תקצירי
  האתר וגם על קופי ידני.
- **אין תביעת השתקה** — הפינה הזו הוסרה מהעיצוב החדש.

## 26 הפינות הקבועות

פס טריקולור · לוגו+תאריך · **פתיח עורך** · פרויקט מתעדכן · תחקיר השבוע (lead) · הנתון של השבוע ·
בעקבות הפרסום (followup) · עוד שקרו השבוע (rundown) · **תמונת השבוע** · מתחת לרדאר (hero) ·
ריל · שיתוף (collab) · ציטוט השבוע · דעות וטורים · המלצות קריאה (עין השביעית + שקוף) · באנר תמיכה · פוטר.

## מה אוטומטי מול מה דורש שיפוט

| אוטומטי לגמרי (מ-WordPress/RSS) | auto-draft — לסמן ולאשר עם דור |
|---|---|
| lead, hero, rundown, opinions (feature+items) | **פתיח העורך** (טקסט עורך) |
| מחברים, תאריכים, תמונות, קישורים | **תמונת השבוע** (פלאש90 — בחירת תמונה+כיתוב) |
| המלצות קריאה (עין השביעית + שקוף, RSS) | הנתון של השבוע (גרפיקת דאטה + מקור) |
| הגהת מקף | פרויקט מתעדכן · ריל · followup · טקסט הציטוט |

פינות ה-auto-draft מסומנות בצהוב ב-preview ומודפסות תחת `TO FILL` בסוף ה-build.

## תהליך העבודה

הכל רץ מתיקיית עבודה (לא בריפו). קבע `SC` לתיקיית ה-scripts של הסקיל:

```bash
SC="$(ls -d ~/.claude/plugins/cache/hamakom-plugins/hamakom-desk/*/skills/hamakom-newsletter/scripts 2>/dev/null | sort -V | tail -1)"
SC="${SC:-$HOME/Developer/hamakom-claude-plugins/plugins/hamakom-desk/skills/hamakom-newsletter/scripts}"
mkdir -p ~/claude/Projects/ניוזלטרים/build && cd ~/claude/Projects/ניוזלטרים/build
```

### 1. משיכה (אוטומטי)

```bash
DAYS=7 PYTHONPATH="$SC" python3 "$SC/fetch_articles.py"
```

מייצר `articles.json` (מילון slug→רשומה) ו-`issue.draft.json` (שלד עם כל הפינות ממולאות
אוטומטית + המלצות קריאה חיצוניות). **שבוע עריכתי של דור = ראשון עד ראשון**, לא חלון נע — כשדור
מבקש "מה עלה השבוע", התאם את `DAYS` כך שיכסה מיום ראשון של השבוע הנוכחי.

### 2. השלמת פינות השיפוט

העתק `issue.draft.json` ל-`issue.json` ומלא/אשר את פינות ה-auto-draft:
- **פתיח עורך** — קרא את `editor_note.headline` + `paragraphs`. נסח פסקה-שתיים בקול האתר (יבש,
  ישיר, בלי פאתוס). אם דור לא סיפק — סמן כ-draft והצע ניסוח.
- **תמונת השבוע** — בחר תמונת פלאש90 רלוונטית לכתבה מרכזית; מלא `img` (URL), `caption`
  (מקום+הקשר+תאריך), `credit`. זו פינת שיפוט — הצג לדור לאישור.
- **הנתון / פרויקט / ריל** — אם יש נכס קמפיין (גרפיקה, וידאו) מלא; אחרת השאר ריק (הפינה תיעלם).
- **ציטוט** — `slug` כבר מצביע על טור; אפשר להחליף ל`text`+`attrib` חופשי, כולל **מתקשורת אחרת**.

### 3. בנייה + הגהה

```bash
python3 "$SC/build_newsletter.py" issue.json
# גרסה בלי טקסט עורך:  NO_EDITOR=1 python3 "$SC/build_newsletter.py" issue.json
```

מייצר `newsletter_<stamp>.html`, מדפיס איזון תגיות + רשימת `TO FILL`. ההגהה (נרמול מקף) אוטומטית.

### 4. אימות ויזואלי — חובה, לפני שמראים לדור

**לעולם לא להראות פלט שלא נראה בעיניים.** רנדר לתמונה וקרא אותה פינה-פינה:

```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
F=$(ls -t newsletter_*.html | head -1)
"$CHROME" --headless=new --disable-gpu --hide-scrollbars --window-size=640,9000 \
  --default-background-color=ffffffff --screenshot=/tmp/nl.png "file://$PWD/$F"
```

חתוך ל-2-3 חלקים (`sips`/PIL) וקרא כל חלק. ודא: פונטים נכונים (Suez One כותרות, IBM Plex גוף),
אפס קווים ארוכים (`grep -c "—\|–" "$F"` = 0), כל הפינות קיימות, תמונות נטענות. תקן ורנדר שוב.
רק אז פתח לדור (`open "$F"`).

### 5. שליחה

**הסקיל לא שולח.** דור מעלה ל-Brevo/Sendinblue ושולח בעצמו. מסור לו את נתיב ה-HTML.
