# hamakom-monthly-newsletter — הניוזלטר החודשי

הגרסה החודשית. **אותו מנוע ואותה מערכת עיצוב** כמו השבועי (`hamakom-newsletter`), עם ארבעה הבדלים
ויזואליים שמבדילים מהדורה ברורה:

1. **צבע אקסנט = אברש (heather #8E6FA8)** במקום טרקוטה — התוויות, הקיקרים, הכפתורים והמספרים
   בסגול-חציל. פס-החתימה הטריקולור **נשאר זהה** בשתי המהדורות (DNA מותגי). מופעל דרך
   `"accent": "heather"` ב-`issue.month.json`.
2. **כותרת:** "הניוזלטר החודשי · <חודש> <שנה>" במקום תאריך שבועי.
3. **קופסת "החודש במספרים":** מיד אחרי בלוק הפרויקט — 4 מספרים גדולים באברש (כתבות שפורסמו,
   תחקירים וידיעות, טורים ודעות, כתבים וכותבים). מחושב אוטומטית; דור יכול להוסיף/להחליף מספרים
   ידניים (ביקורים באתר, תורמים חדשים) על ידי עריכת `stats` ב-`issue.month.json`.
4. **טווח:** `DAYS=30`, וכל התוויות ל"החודש" (תחקיר החודש, הנתון של החודש וכו').

כל שאר הפינות זהות לשבועי (ראה `hamakom-newsletter/SKILL.md` לפירוט 26 הפינות ופינות השיפוט).

## אחידות עיצוב — מנוע משותף

הסקיל **לא** מחזיק עותק משלו של `build_newsletter.py`. הוא בונה עם המנוע של `hamakom-newsletter`
(סקיל אחות באותו פלאגין), כדי שכל שינוי עיצוב יחול על שניהם בבת אחת. מצב "חודשי" מופעל דרך שדות
ב-`issue.month.json` בלבד (`edition_label`, `period`, `stats`, `stats_label`).

## תהליך העבודה

```bash
# תיקיות ה-scripts של שני הסקילים (אחות תחת אותו פלאגין)
MSC="$(ls -d ~/.claude/plugins/cache/hamakom-plugins/hamakom-desk/*/skills/hamakom-monthly-newsletter/scripts 2>/dev/null | sort -V | tail -1)"
MSC="${MSC:-$HOME/Developer/hamakom-claude-plugins/plugins/hamakom-desk/skills/hamakom-monthly-newsletter/scripts}"
WSC="$(dirname "$(dirname "$MSC")")/hamakom-newsletter/scripts"   # המנוע המשותף
mkdir -p ~/claude/Projects/ניוזלטרים/build && cd ~/claude/Projects/ניוזלטרים/build
```

### 1. משיכה (אוטומטי, 30 יום)

```bash
DAYS=30 PYTHONPATH="$WSC" python3 "$MSC/fetch_month.py"
```

מייצר `articles.json` + `issue.month.draft.json` — כולל קופסת "החודש במספרים", המלצות קריאה
חיצוניות (עין השביעית + שקוף), וכל הפינות ממולאות אוטומטית. תווית החודש נגזרת אוטומטית (אם רצים
בתחילת חודש — החודש שחלף).

### 2. השלמת פינות השיפוט

`cp issue.month.draft.json issue.month.json` ומלא/אשר: פתיח עורך (סיכום החודש בקול האתר), תמונת
החודש (פלאש90), ואם רוצים — מספרים ידניים ב-`stats` (ביקורים, תורמים). פינות נכס (נתון/פרויקט/ריל)
— מלא אם יש, אחרת הן נעלמות.

### 3. בנייה (מנוע משותף)

```bash
python3 "$WSC/build_newsletter.py" issue.month.json
# בלי טקסט עורך:  NO_EDITOR=1 python3 "$WSC/build_newsletter.py" issue.month.json
```

ההגהה (נרמול מקף ארוך) אוטומטית, כמו בשבועי.

### 4. אימות ויזואלי — חובה

זהה לשבועי: רנדר ל-PNG (`chrome --headless --screenshot`, `--window-size=640,9000`), חתוך וקרא
פינה-פינה. ודא במיוחד: הכותרת מציגה "הניוזלטר החודשי · <חודש>", קופסת "החודש במספרים" עם 4 מספרים
נכונים, אפס קווים מפרידים ארוכים. רק אז `open` לדור.

### 5. שליחה

**הסקיל לא שולח.** דור מעלה ל-Brevo ושולח. מסור לו את נתיב ה-HTML.

## כללי ברזל

כמו בשבועי: עברית נקייה בקול האתר (יבש, ישיר, בלי פאתוס), בלי אימוג'ים, בלי תביעת השתקה, אסור
לאזכר כתבה בלי לקרוא, ואסור לדרוס עריכות ידניות של דור ב-`issue.month.json`.
